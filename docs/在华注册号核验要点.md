# 在华注册号核验要点（进口业务适用）

面向进口商、单证与跟单人员的实用说明。所有结论以中国海关总署系统返回为准，本文为业务操作参考。

---

## 一、什么是在华注册号

在华注册号，官方名称为**进口食品境外生产企业注册编号**（行业习惯叫在华注册号、GACC 注册号）。境外生产企业向中国海关总署申请注册，获批后取得一串编号，通常以 **C** 或 **Q** 开头，由字母、国家代码、日期码和序列号组成。

这串号码会出现在两个地方：

1. **COO 原产地证书**上 Producer 栏的 `CHINESE REGISTRATION NUMBER` 字段
2. **中文标签**上的境外生产企业注册编号项

海关在入境环节核对这两个位置的号码与系统登记是否一致。

## 二、哪些货需要关注

需要境外生产企业注册的进口货物，典型包括：

- 进口食品与食品原料
- 农产品（含杂粮、豆类等）
- 部分饲料原料与饲料添加剂

具体品类以海关总署公布的注册目录为准。同一品类、同一境外工厂，注册状态可能随有效期和产品范围变动，因此**每票都要重新核，不能沿用上次的结论**。

## 三、号码格式长什么样

以 C 或 Q 开头，其后依次为：

- 国家或地区代码
- 产品类别代码
- 日期码
- 流水号

号码为连续字符串，中间没有空格。这一点在识读时很关键：COO 扫描件上的号码常因为字符间隙被误读成带空格，导致查询查不到。**高 DPI 渲染后逐字符核对**，是准确核验的前提。

## 四、六个必须逐项核对的维度

| 维度 | 核什么 | 不过关的后果 |
|---|---|---|
| 号码存在性 | 总署系统里查得到这个号 | 查不到即无法清关，退运或销毁 |
| 注册状态 | 是否有效，有无注销、过期 | 状态异常等同无号 |
| **企业名称一致性** | 系统登记的企业名与单据上的生产商是否同一家 | 串号抄错，单证不符，责任在己方 |
| 产品范围 | 登记的品类是否包含本批货物 | 该号不适用于本批，重新出证或退运 |
| 有效期覆盖装船日 | 有效期区间是否涵盖实际装船日期 | 装船时该号已失效 |
| 原产国一致性 | 登记国别与单据原产国是否一致 | 登记信息与实际不符 |

**企业名称一致性是必做项，不能省。** 只查号码有效性会漏掉"号码真实但抄成别家"的情况，这是最常见的翻车类型。

## 五、高频翻车场景

**场景一：抄成别家企业的号。** 上一票货物的 COO 和这一票的模板混用，注册号没换。号码本身真实有效，单从号码查不出来。

**场景二：空格误读。** 扫描件上号码字符间隙被读成空格，查询接口查不到，误判为无效号码。

**场景三：有效期没覆盖装船日。** 注册有效期到期日早于实际装船日，装船时该号已失效。

**场景四：产品范围不含本批货。** 企业注册的是 A 品类，本批是 B 品类，号码存在但不适用。

**场景五：中文标签与 COO 不一致。** 标签上的注册号、生产企业名称或原产国与 COO 对不上，到港后要求整改。

## 六、常见问题

**问：查不到号码，是不是就是假号？**
不一定。可能是号码识读有误、企业名换过、或者查询口径问题。应当先用企业名称做兜底模糊检索再下结论，不查明白就判无效会误伤正常业务。

**问：接口连不上怎么办？**
判"未完成核验"，等接口恢复再验，或者改用人工登录海关总署公开系统核对。绝不把接口不通当作号码无效的证据。

**问：上一次验过了，这次还要验吗？**
要。注册状态、有效期、产品范围都可能变动，每票独立核验。

**问：YA 开头 18 位的号码怎么核？**
那是进口食品境外出口商备案号，与本技能覆盖的境外生产企业在华注册编号不是同一类，需走另外的核验口径。

## 七、本技能帮你做什么

`verify_gacc.py` 脚本联网查询海关总署公开系统，一次性完成上述六个维度的比对，输出 JSON 结果，再由 `build_report.py` 引入 HTML 审查报告，不靠人眼转录。

核验要点：

- 企业名称一致性必做
- 查不到时自动兜底检索
- 接口不通判"未完成核验"，不误判
- 结果以 JSON 落盘，报告直接引用，避免手写转录出错

调用示例：

```bash
python scripts/verify_gacc.py \
  --reg-no <号码> \
  --producer "<单据上的生产企业英文名>" \
  --product "<本次商品名称>" \
  --ship-date <装船日 YYYY-MM-DD> \
  --country "<单据原产国>" \
  --json-out <工作目录>/gacc.json
```

参数按手上有的信息给，缺哪几项就跳过对应维度，不要为凑参数编造。只做号码存在性核验时，只传 `--reg-no` 即可。

## 八、免责说明

相似度阈值属于启发式规则，不是官方判定标准。核验结论供业务判断参考，最终以中国海关总署系统返回为准。所有提示为 warn 或 bad 的项目，须业务负责人复核并与对方书面确认后方可放行。
