# 中英文标签核对规则

## 一、核对目的

进出口单据常出现中英文混排，且进口货物另附中文标签。语种不一致会引发三类实际后果：

1. **通关受阻**：中文标签品名与 HS 编码、检疫准入品名对不上，口岸查验时被要求整改。
2. **单证不符遭拒付**：信用证项下同一票货在不同单据出现不同英文写法，构成不符点。
3. **追溯断裂**：中文标签上的注册号、批号与 COO、重量质量证不对应，出问题时无法溯源。

核对采取三栏对照：单据英文值、对应中文值、判定。

## 二、单据字段中英对照核对点

| 核对点 | 要求 | 常见问题 |
|---|---|---|
| 品名 | 英文品名与中文品名须对应同一商品，且与 HS 编码匹配 | 同义词混用，见第四节 |
| 规格 | 纯度/等级的中英文表述须一致 | 英文写 P99%，中文只写"一级"，等级口径丢失 |
| 原产国 | 单据英文国名与中文国名须指向同一国家 | 缩写歧义，如 AU（澳大利亚/奥地利单位） |
| 装港卸港 | 中英文港口名须为同一港口 | 旧式译名，见第四节 |
| 计量单位 | 中英文单位须等价 | MT 与"吨"混用时不区分公吨/长吨/短吨 |
| 包装 | 中英文包装描述须一致 | 英文 JUMBO BAG，中文写"编织袋"，吨袋属性丢失 |
| 企业名 | 中英文企业名称须对应同一主体 | 英文全称与中文营业执照名不一致 |
| 币种与金额 | 英文大写金额与数字金额须一致 | SAY 大写金额漏写 ONLY 或与数字不符 |
| 日期 | 各单据日期格式可不同，但指向须同一天 | 日月顺序误读，见第四节 |
| 唛头 | N/M、NO MARK、"无唛头"三者等价 | 一处标 N/M，另一处标具体唛头，自相矛盾 |

## 三、中文标签合规要素（进口业务适用）

按品类适用的监管要求，核对以下要素是否齐备并与单据一致：

| 要素 | 与单据交叉核对点 |
|---|---|
| 品名 | 与合同品名、COO 品名对应，且与 HS 编码及检疫准入品名一致 |
| 原产国 | 与 COO 原产国、GACC 登记国别一致 |
| 在华注册号 | 与 COO 上 CHINESE REGISTRATION NUMBER 一致，且经 GACC 系统核验，见 `gacc_registry.md` |
| 境外生产企业 | 与 COO 第 2 栏 Producer 一致，且与 GACC 登记企业名一致 |
| 境外出口商 | 与发票签发方一致，可不同一主体但须在标签注明 |
| 生产批号 | 与重量质量证、植检证批号对应 |
| 生产日期与保质期 | 逻辑自洽，且与装船日不矛盾 |
| 净含量规格 | 单件净重 × 件数与装箱单总重验算一致 |
| 贮存条件 | 与货物特性相符，不影响品质判定 |
| 境内代理商 | 名称与地址齐备，须具备相应资质 |

## 四、常见中英错配陷阱

| 类型 | 高风险写法 | 处置 |
|---|---|---|
| 同义词混用 | polyethylene 与 polythene；paracetamol 与 acetaminophen | 同一票货所有单据固定一种写法，差异标 warn 并请业务方确认 |
| 旧式译名 | Tsingtao 与 Qingdao；Canton 与 Guangzhou；Peking 与 Beijing | 指向同一港口/城市时判 ok，但在说明中注明属旧译名 |
| 单位不对应 | MT 译作"吨"而未区分公吨/长吨/短吨 | 换算口径不一致时标 warn，须明确计量基准 |
| 日期顺序 | 08/09/2026 在英式与美式下分别为 9 月 8 日与 8 月 9 日 | 一律标 warn，须与业务方确认口径后再判定 |
| 包装口径 | JUMBO BAG / BIG BAG / TON BAG / FIBC 同义，译作"编织袋"会丢吨袋属性 | 中文须体现集装袋属性，否则标 warn |
| 大写金额 | SAY 金额与数字不符，或漏 ONLY 收尾 | 直接标 bad，属重大不符 |
| 企业译名 | 英文全称与中文营业执照名不对应 | 标 bad，可能影响收付汇与退税 |
| 唛头矛盾 | 一处 N/M，另一处标具体唛头 | 标 bad，须统一 |

## 五、常用术语对照

单据类型：Sales Contract 销售合同 / Commercial Invoice 商业发票 / Packing List 装箱单 / Bill of Lading 提单 / Certificate of Origin 原产地证 / Phytosanitary Certificate 植物检疫证书 / Weight & Quality Certificate 重量质量证明书 / Fumigation Certificate 熏蒸证书

贸易术语：EXW 工厂交货 / FOB 装运港船上交货 / CFR 与 CNF 成本加运费 / CIF 成本加保险费加运费 / DAP 目的地交货 / DDP 完税后交货

计量与包装：MT 与 Metric Ton 公吨 / KG 千克 / BAG 袋 / PP WOVEN BAG 聚丙烯编织袋 / JUMBO BAG 与 FIBC 吨袋 / PALLET 托盘 / IN BULK 散装 / GROSS WEIGHT 毛重 / NET WEIGHT 净重

单据状态：PROFORMA 形式（非正本）/ DRAFT 草本 / FULL SET OF ORIGINAL 全套正本 / N/M 与 NO MARK 无唛头 / AS PER 按照 / AT SIGHT 见票即付

## 六、判定规则

- 中英文指向同一主体且口径完整 → ok。
- 指向同一主体但口径有信息损耗（如吨袋译作编织袋） → warn。
- 指向不同主体、不同国家、或数值矛盾 → bad。
- 缺少对照对象（如出口业务无中文标签） → pending，并在报告中注明审查范围。
- 术语等级差异不改变商品实质时（如 CFR 与 CNF、JUMBO BAG 与 FIBC）判 ok，但在说明中标注属同义写法。
